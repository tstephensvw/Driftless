# Driftless

Interactive guide for Switch remote overhaul.

**Live playbook:** https://tstephensvw.github.io/Driftless/

Operation Driftless is a self-contained repair playbook for rebuilding six
Nintendo Switch Joy-Con controllers — drift-proof magnetic sticks, new
batteries, SL/SR ribbons, shells and grips. It is read off an iPad at the
workbench.

Everything lives in `index.html`. There is no build step. Pushing to `main`
publishes the site automatically via `.github/workflows/deploy.yml`.

- `CLAUDE.md` — project context and design rules for AI coding sessions.
- `ROADMAP.md` — planned features and their status.
